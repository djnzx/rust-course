###

- Rust не має GC, тому всі операції з памʼяттю виконуються виключно вручну, як у C
- Rust працює без GC лише у debug-режимі, а у release-режимі використовує прихований runtime
+ Rust не використовує GC, але забезпечує безпеку памʼяті через статичну систему типів і контроль володіння, що перевіряється компілятором
- Rust компенсує відсутність GC використанням винятків (exceptions) для контролю життєвого циклу обʼєктів

### Яка з наведених характеристик **найкраще відображає філософію дизайну Rust**, виходячи з переліку його особливостей у лекції?

- Основна ідея Rust — спростити синтаксис у порівнянні з Java та C++ за рахунок динамічної типізації
+ Чітке відділення даних від поведінки та декларацій від реалізацій дозволяє досягати коректності без втрати продуктивності
- Rust орієнтований передусім на швидку розробку UI-додатків і frontend-систем
- Головною перевагою Rust є наявність вбудованого віртуального середовища виконання, аналогічного JVM
